# PhyloPCA: Phylogenetic Signal in Continuous, Discrete and Geometric-Morphometric Data

Simulates continuous, discrete and geometric-morphometric ('shape')
character data on a fixed generative tree, and reconstructs phylogeny
from each using neighbour-joining, maximum parsimony and Bayesian
inference, so that reconstruction accuracy can be compared across data
types and methods. Provides the simulation, alignment, tree-inference
and scoring functions, together with the cached results, underlying
Smith (2026), a reply to Raskin et al. (2026)
[doi:10.1002/ajpa.70306](https://doi.org/10.1002/ajpa.70306) on whether
principal components analysis can recover phylogenetic signal from
continuous morphological data.
